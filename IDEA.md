# Project idea

## One-sentence idea

Describe what you want to build in one sentence.

## Who it is for

Who is the user? What are they doing when they need help?

## The problem

What is difficult, slow, or frustrating today?

## Where the agent lives

Choose one: web app, Slack, mobile app, or another surface.

## Main workflow

Describe one complete interaction from the user's request to the visible result.

## Context the agent should use

What can it see or know in that environment (for example: the current page, a Slack thread, selected data, or phone state)?

## Actions and approvals

What should the agent be able to do? Which actions must wait for the user to approve?

## Data and integrations

List any APIs, files, services, or data sources you want to use. Say `none yet` if undecided.

## What a successful demo shows

Describe the one outcome that would make the demo feel complete.

## Constraints or preferences

Add design, privacy, technical, deadline, or scope preferences here.
